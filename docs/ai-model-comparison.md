# AI 모델 비교 (S2-1) · 2026-10-30

> 결론: **`gemini-3.5-flash-lite`** (Google AI Studio 무료 등급)

## 비교 조건
- 공급자: Google AI Studio의 Gemini API (무료 등급, 프로젝트 `macros`)
- 사진: 음식 사진 20장 (`samples/food/`, Git에 올리지 않음) — 한식, 양식, 디저트, 음료, 과일 한 알, 여러 반찬 상차림을 섞음
- 출력: 기획서 6.3절의 JSON 형식을 `responseSchema`로 강제 (`isFood`, `items[]`, `confidence`, `comment`)
- 무료 한도 (AI Studio 비율 제한 화면 기준)

| 모델 | 분당(RPM) | 하루(RPD) |
|---|---|---|
| gemini-3.8-flash | 5 | 20 |
| gemini-3.5-flash-lite | 15 | 500 |

## 결과

| 항목 | 3.5 Flash-Lite (20장) | 3.8 Flash (10장) |
|---|---|---|
| 성공 | **20 / 20** | **3 / 10** |
| 실패 | 없음 | 120초 시간 초과 4건, `503 high demand` 3건 |
| 걸린 시간 | 평균 **2.5초** (1.7 ~ 5.0초) | 성공한 3건이 12.5초, 89.8초, 103.9초 |
| 음식 이름 | 20장 중 **19장** 맞음 | 성공한 3장은 Lite와 거의 같은 결과 |
| 칼로리 ↔ 탄·단·지 | 1개 항목만 25% 넘게 어긋남 (양배추 샐러드 15kcal vs 19kcal) | — |
| 요청당 토큰 | 평균 약 1,400 | — |

### 3.5 Flash-Lite가 틀리거나 애매했던 것
- **05 스타벅스 프라푸치노 → "아이스 카페 라떼 130kcal"**: 음료 종류를 잘못 봐서 칼로리를 크게 낮게 잡았다 (프라푸치노는 보통 300kcal 이상).
- **01 떡볶이 800g 1,650kcal**: 그릇 하나에 비해 양을 크게 잡은 것으로 보인다. 칼로리 자체는 탄·단·지 합과 맞는다.
- **15 한정식 상차림**: 반찬 여러 개를 "각종 반찬 및 나물류 300g"으로 묶었다. 상차림 사진은 원래 어려운 경우라 받아들일 만하다.

## 결정과 이유
- **3.5 Flash-Lite**: 하루 500건으로 지인 베타(5~10명)에 충분하다. 빠르고, 비교한 20장에서 한 번도 실패하지 않았다.
- **3.8 Flash는 쓰지 않는다**: 하루 20건뿐인 데다, 무료 등급에서 실패하거나 1~2분 걸리는 경우가 대부분이었다. 결과 화면에서 최대 60초까지만 기다리기로 한 기획과 맞지 않는다.
- AI 연결 코드를 `FoodAnalyzer` 인터페이스 뒤에 두므로, 나중에 모델을 바꿀 때는 `app.gemini.model` 설정만 바꾸면 된다.

## 다음 조각에 반영할 것
- **503(혼잡), 시간 초과도 실패로 처리하고 자동 재시도 대상에 넣는다** (S2-4). 무료 등급은 혼잡에 따라 같은 모델도 응답이 크게 달라진다.
- **요청 시간 제한**은 30초 정도로 둔다. Lite는 5초를 넘은 적이 없다.
- **서비스 하루 분석 상한**은 450건 정도 (무료 한도 500보다 조금 낮게, S2-4).
- **무료 등급은 올린 사진이 Google 제품 개선에 쓰일 수 있다** (가격표 "Google 제품 개선에 사용됨: 예") → 글쓰기 화면과 개인정보처리방침에 안내 (S2-3).
- 음료(프라푸치노 vs 라떼)처럼 겉모습이 비슷한 것은 틀릴 수 있다 → 결과 옆에 "AI 추정치" 면책 문구 (기획서 8절).

## 사용한 지시문
```
당신은 영양 분석 도우미입니다. 사진 속 음식을 보고 영양 정보를 추정하세요.
- 음식 사진이 아니면 isFood=false, items는 빈 배열로 답합니다.
- 음식이면 보이는 음식(반찬 포함)마다 하나씩: 한국어 이름(name), 사진 속 양의 추정 무게(amountG, g), 칼로리(kcal), 탄수화물(carbsG), 단백질(proteinG), 지방(fatG)을 추정합니다.
- 양은 그릇 크기와 일반적인 1인분을 기준으로 추정합니다.
- confidence: 추정의 확신 정도 (LOW / MEDIUM / HIGH)
- comment: 어떻게 추정했는지 한국어 한 문장
```
